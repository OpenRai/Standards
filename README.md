## Document Statuses

- **Working Draft:** A reviewable proposal that can still change as implementations and feedback develop.
- **Implementation Draft:** A proposal with at least one working implementation. Details can still change before the document becomes stable.
- **Stable:** A specification considered suitable for broad interoperability. Changes should preserve compatibility.
- **Informational:** Guidance or background material that does not define an interoperability contract.
